# 节能评审专家组总体意见

从第三方评审单位的角度，根据本项目专家意见和资料编制专家组总体意见。执行当前用户要求，保护项目资料与现有文件。

## 1. 查找资料与核对专家

查找用户指定的模板、项目总体意见文件、专家个人意见、送审报告、委托协议及评审记录。区分不同专家与同一专家的 Word、PDF 版本，内容冲突时查明有效版本。扫描件须读取原页，不能靠文件名判断内容。

核对实际应有专家人数，通常为五人。若收集的独立专家意见不足应有份数，立即询问使用者选择「根据现有意见先形成总体意见」或「等待收齐」。未得到答复前，不将不完整意见写为完整专家组意见；可继续读取现有资料。用户明确指定其他人数时按指定人数执行。

## 2. 选模板并核对项目事实

优先采用当前项目已有的总体意见模板或用户指定模板；没有模板时用 assets/template.docx。按模板保留标题、工作开展概况、会议情况、总体评价、意见与建议、签名和落款的结构、字体、字号、行距、页边距、编号、下划线和签名区。仅替换项目应填写的信息及授权修改的意见与建议。不得自行改写模板固定表述或调整版式。

从委托协议、送审报告、可靠的评审记录或已确认的项目材料识别项目、建设单位、编制单位、委托单位、评审组织单位、评审日期与方式。核对同名单位的角色，不能把编制单位当评审单位。记录来源并交叉核对；材料冲突或核心信息缺失时明确询问，不能沿用其他项目名称、数据、日期或结论。

## 3. 汇总意见

逐份提取修改对象、问题及修改动作，按主题合并相近意见。保留影响项目边界、产品与工艺、设备选型、能源消费、能效、碳排放和节能措施结论的关键要求。以专家组口吻使用“核实、补充、完善、复核、细化”等动词，参照模板的简洁程度，每条指出对象与动作。可用“其他详见专家个人意见”承接细节，不能借此省略影响核心判断的意见。

核实专家提出的标准、参数、系数及其适用口径，适用的时效性依据查官方来源。来源缺失时如实写成需要核实的事项并向使用者说明。以实际项目材料及专家意见为依据，不虚构事实、不代替专家作出未经支持的通过结论，也不将个别专家建议扩大为无依据的强制要求。

## 4. 生成与验收

在模板基础上修改对应内容。汇总“意见与建议”时保留前面的固定内容和总体结论，签名留空；需要更改既有固定表述或页面时，先取得用户明确要求。已有模板前置内容确有明显事实冲突时，先报明问题及依据，避免私自改写。

核对项目与单位名称、日期、专家份数、意见覆盖、编号连续、签名栏、页面设置、分页及遮挡。优先使用 Word/WPS 预览，可用其他工具时说明实际使用的环境。页数发生变化不自行缩小字号或修改行距；先检查页面是否符合模板，确需调整时听从使用者要求。说明不能核实的内容及预览限制。

默认生成正式稿。用户指定仅审阅或另存时遵从其指示。替换现有正式文件前，在已有工作区或备份目录保留替换前文件；没有时在项目目录创建清楚标识的备份目录。验证备份后替换，并核对正式稿与交付稿一致。文件被占用时保留待交付稿，避免覆盖未保存的改动，处理占用后完成替换。报告正式稿、底稿位置、专家意见份数和重要未决事项。
