# 七章编制指引

国仕正式成品通常采用以下七章。按照所选模板的实际层级和命名编排。先确定每节要回答什么，再到指定报告和本项目评审资料定位，避免通篇搬入报告。正文中的评审表述跟着实际事实、表格和结论走。

| 章节 | 先在什么地方找 | 怎样编制与复核 |
| --- | --- | --- |
| 一、评审过程 | 委托和送审资料、会议材料、修改记录、项目实际适用依据 | 沿用评审依据、范围和过程三块。写清评审范围内的工程、用能系统及评价事项，依当期口径核对文件名称、版本和适用日期。沿时间顺序写主要评审节点，与评审过程说明交叉核对。 |
| 二、项目简况 | 报告建设单位与项目概况、产品或功能方案、建设进度；项目备案等附件用来核对 | 依模板提取建设单位、项目地点、性质、规模、主要内容和进度。制造业关注产品及产能、厂区用途；建筑类关注功能、建筑面积和配套。改扩建按指定报告分清原有工程、本次变化、投产后全厂，工程边界及产能在第三至七章一致。 |
| 三、项目能源消费及其影响 | 报告各能源消费量、年综合能耗及属地影响分析表；适用时查碳排放段落及表 | 先交代电、燃料、热力及耗能工质等边界、数量和单位，再用报告对应表呈现项目总消费量。若报告和模板区分生活用能及扣除生活用能后的能耗，分别取三种口径。改扩建分清新增和建成后总量。按报告区分当量值、等价值、外购和自用能源，并核对区域影响分析所使用的数值是否与口径对应。按项目适用条件编入碳排放、化石能源和区域影响等模块。 |
| 四、项目主要能效指标水平 | 报告的产品能耗、建筑能耗、可比项目、产值或增加值能耗等评价；必要时跨章节找比较表及来源 | 将指标、单位、分子和分母、对标值和结论写在一起。制造业优先用适用的单位产品或工序指标，建筑类按功能采用面积等指标；配套建筑指标按报告口径处理。限额、标杆、同类项目及地区指标按各自用途呈现。东莞区域对标的参考年份、数值及项目对比项均从当期报告取用，可组合散见于报告各处的资料。依据不足就在相应处标注复核。 |
| 五、项目主要建设方案 | 报告的工艺、总图、主要用能工序和设备，供配电、暖通、照明、给排水、计量管理等章节 | 按模板小节说明方案及节能评价。制造业用报告工艺、主要生产设备和附属设备；按项目需要用流程图、工序能耗及公辅系统信息。建筑类写总平面、围护、照明、空调通风、给排水及电梯等适用内容。设备一览表选中报告对应原表**整表复制**，表格过长可按模板排跨页及重复表头，数值和行列保持一致。检查设备数量、能效等级、计量分类、图表题和正文引用。 |
| 六、节能措施 | 报告的节能技术措施、管理措施和节能效果汇总 | 沿用国仕小节和表格次序，提取本项目实际措施、主要设备和适用条件。报告有定量效果时取用对应数值、单位及合计，区分预计和已实施情况。正文、措施表、汇总表和末章使用同一套数据。 |
| 七、评审结论及建议 | 同类国仕模板的末章、意见第一至六章及当期报告的支撑内容 | 完整套入模板的适用栏目和固定表述。逐项填写依据适用性、内容深度、建设方案、主要设备能效、措施、能源消费及能效等内容。按模板填本项目具体量值、能效评价及后续建议。项目数值、判断和适用条件均回查前文。 |

## 有变化时怎么同步

| 报告改动 | 意见里一起检查的位置 |
| --- | --- |
| 项目名、建设规模、产能、工程边界 | 封面、页眉页脚、第一和第二章；第三、四、七章的边界与指标；两份配套文件中的项目名称。 |
| 能耗、供能方式或分类边界 | 第三章分项及汇总、第四章能效及对标、第六章有关措施效果、第七章能耗和能效结论。按实际关联检查生活用能、当量值及等价值。 |
| 设备数量、参数或能效等级 | 第五章整表及表前表后评价，受影响的用能计算摘录及第七章结论。报告已修正后用对应新表替换旧表。 |
| 对标资料或措施效果 | 第四章项目指标及比较评价、第六章措施及节能量汇总、第七章相关结论与建议。 |
| 评审流程节点 | 第一章和过程说明的相应日期、轮次和事项。 |

底稿按“意见位置｜报告版本及页码或表号｜需复核事项｜关联位置｜更新状态”记录需跟踪的内容。遇原表号与模板表号不同，标题和正文引用跟着当前意见文件的实际编号核对，原报告表号留在底稿。

同一指标在报告中同时有当量值和等价值时，先查模板评价栏目、报告对应对标段和分母，再取该栏目实际使用的口径。其他报告口径保留在核对底稿备用。跨章发现数值不同，先分清工程边界、计量范围和指标口径；材料不足以解释时在对应位置标注复核。
