# 常见问题与简短批注对照

先依据项目资料核实，示例用于表达方式，不代表每个项目都存在问题。优先选中具体数字、文字或表格；数字错误写“复核”，同一问题重复出现写“同上”，同步位置写“同步复核”。本清单结合用户给出的 36 项要求和历史材料中的检查线索归纳；版本不明、锚点缺失、空白或意见性质无法确认的历史记录只作待核线索，不计作已确认经验。历史意见、回复及项目特定结论不得直接移植。

| 检查位置或问题 | 怎么核实 | 批注示例 |
| --- | --- | --- |
| 专家意见答复遗漏或不完整 | 对意见、回复和实际章节逐条对照 | “补充专家意见修改答复” |
| 意见回复说已修改但正文未落实 | 查正文、图表和附件 | “这项还没改到位，复核” |
| 封面稿别、签字及目录 | 结合本轮资料和适用要求核对修编稿标识、编制人员签字、目录和页码 | “补充修编稿标识” |
| 报告格式、表格字体 | 对照所用指南、正文和表格；指南“可参考”不等于强制 | “表格字体复核” |
| 建设性质、改扩建范围 | 对照备案、原有项目与本次建设范围 | “本次评价范围明确一下” |
| 立项管理类型 | 核对备案、核准或审批文件及项目性质，报告表述与现有有效文件不一致时请编制单位核实 | “立项类型复核” |
| 备案、环评或用地资料不一致 | 对照实际有效资料中的规模、投资、设备及版本；资料之间冲突时列出差异，不能直接假定哪一份正确 | “与附件数据不一致，复核” |
| 拟开工时间已过 | 对照审查日期和现场材料 | “是否已开工、停工？补充近期现场照片” |
| 建筑用途及功能 | 对照建筑一览表、总图、工艺和平面 | “补充宿舍、食堂等区域” |
| 计容、不计容与总面积 | 核对各分项面积、计算规则及设计资料；加总关系须按各项实际统计范围判断 | “建筑面积统计口径复核” |
| 建筑层高及给水 | 对照建筑方案、供水分区和扬程 | “补充层高，复核扬程” |
| 停车位和充电设施 | 对照设计方案、负荷计算和用电边界 | “明确停车位、充电桩数量” |
| 充电桩快慢充配置 | 结合车辆类型、停放时间、分期方案及实际需求，核查快充与慢充配置和负荷；不能预设每个项目都必须配置快充 | “快慢充配置是否合适？” |
| 充电桩使用及产权 | 明确自用、公共经营、产权和供电计量边界，与项目能源核算相匹配 | “充电桩用途及产权明确一下” |
| 人员与工作制度 | 对照生产能力、食宿和各系统运行时间 | “人员及食住情况明确一下” |
| 研发与办公区域混写 | 核实研发设备、使用面积、运行制度与办公用途是否可分开，核算及对标采用相同边界 | “研发和办公区域分别明确” |
| 宿舍容量与入住人数 | 对照床位、住宿人数及实际生活区设置 | “复核宿舍与居住人数的匹配性” |
| 产能和产品边界 | 对照备案、工艺产线及各产品产量 | “各产品产量及范围明确一下” |
| 原材料与产量不匹配 | 对照工艺、损耗、产出及去向 | “原料与产量复核” |
| 指标优化和建设方案对比 | 比较同口径方案及前后表格 | “前后数据复核” |
| 方案比选套话 | 对照实际工艺、备选方案、差异和选用依据 | “结合项目实际比选” |
| 总图与文字不一致 | 对照厂房、物流、机房及布置图 | “和总平图核对” |
| 总平图朝向不清 | 检查指北针、建筑朝向与分析文字是否一致 | “补充指北针” |
| 已建、拟建与新增混用 | 对照备案、现场、设备来源和计算边界 | “设备现状明确一下” |
| 用能工序遗漏 | 对照工艺图、设备表和计算表，关注热源和烘干 | “补充该工序用能分析” |
| 生产设备清单矛盾 | 对照型号、台数、功率、工序和能耗 | “前后设备数量复核” |
| 环保处理设施及用能 | 对照环评、工艺和实际设施，核查除尘、废气、污水处理等设备是否纳入能耗，处理方式是否与污染物相符 | “环保设施及用能复核” |
| 单台设备大于 100 kW | 对照额定功率并查是否逐台分析 | “补充该设备节能分析” |
| 设备运行、备用不明 | 与生产班次、负荷和运行台数对照 | “运行和备用台数明确一下” |
| 专用设备能效无适用依据 | 核实类型、标准范围、工况和指标 | “设备能效对标依据？” |
| 空压机选型 | 对照用气点压力、流量、同时率与产气 | “补充用气需求，复核空压机配置” |
| 空压机能效混用 | 区分整机比功率、整机等级与电机等级 | “复核空压机整机能效” |
| 供电方案及备用 | 核对供电电压、路数、容量和备用 | “几路进电？有备用电源吗？” |
| 用电负荷等级 | 结合各类设施的供电可靠性要求，核对负荷等级、备用电源与设计方案 | “补充主要负荷等级” |
| 柴油应急电源及用能 | 核实是否配置应急发电机、燃料和运行情景，再按适用核算边界复核是否遗漏 | “补充应急电源及柴油用量说明” |
| 容量估算 | 对照负荷分类、需要系数、功率因数及补偿 | “需要系数、功率因数复核” |
| 变压器负载 | 对照运行工况、台数、计算负荷及损耗 | “变压器负载率复核” |
| 空调功能区或洁净需求 | 核对各区用途、负荷、新风及洁净条件 | “各区域空调方案明确一下” |
| 空调末端设备漏算 | 核对主机、水泵、冷却塔、风机盘管及新风末端，结合实际运行制度复核用电 | “补充空调末端用电” |
| 冷水机组单台容量 | 对照冷负荷、机组台数、单台容量、分期运行及备用方式，复核各运行工况是否匹配 | “复核冷水机组选型” |
| 空调面积重复或漏算 | 对照各功能区实际空调范围与面积统计，核实走廊、公共区域等是否已包含；不能一概扣除 | “空调面积范围复核” |
| 通风、水泵选型 | 对照实际风量风压、用水量、供水高度和设备曲线 | “设备选型复核” |
| 给水泵流量及分组 | 按最高日、最大时用水需求和供水分区，核查泵组流量、数量、功率及运行／备用状态 | “给水泵流量及分组复核” |
| 生活与消防给水混写 | 对照实际消防设计、泵组及用途，核实生活和消防系统配置是否相符 | “生活和消防给水分别说明” |
| 市政给水压力和天然气接入 | 核对可利用市政水压、供气管径、压力及项目用量；缺乏实际供给资料时要求说明 | “市政水压、供气条件明确一下” |
| 地下室用途与通风 | 对照地下停车、设备房等用途，复核排风排烟、控制方案与用能 | “补充地下室节能分析” |
| 照明功率密度 | 区分功能区，核对照明设计功率密度与适用限值及单位 | “补充功率密度限值” |
| 室外照明能效 | 区分室内灯具与室外道路灯具，按实际产品类型核实适用标准和设备能效 | “室外照明对标复核” |
| 电梯性能分析未形成结论 | 核验实际使用类别、运行条件和适用评价方法后形成等级或性能对标 | “补充电梯性能对标结论” |
| 能效一级表述 | 核实产品范围、标识、项目评审要求和设备实际数据 | “能效等级复核” |
| 建筑节能 | 核对建筑用途、围护结构、计算书及专家意见 | “按专家意见补充建筑节能分析” |
| 能源计量 | 对照用能边界、能源介质、主要用能设备及器具 | “补充分项计量方案” |
| 生产和中央空调用水计量 | 对照生产、冷却或空调水系统方案，核查各主要用水单元计量配置与计量精度 | “补充分项用水计量” |
| 分期建设的计量和运行 | 对照各期投产时间、建设内容、设备和能源供应边界，检查计量方案及统计口径 | “各期计量方案明确一下” |
| 光伏及主要用能设备计量 | 对照自发、自用、外送电及适用计量要求，核查分项和主要用能设备计量器具；计量设备判定门槛须查现行标准，不能照搬历史批注或混同于单台大于 100 kW 的评价要求 | “补充光伏及主要用能设备计量” |
| 生活、车库和充电设施用能遗漏 | 核对实际功能、设备清单和能源计算边界 | “生活区用能补充一下” |
| 光伏扣减和外购电 | 分清总发电、自发自用、外送、总用电、外购电及消费量 | “光伏扣减口径复核” |
| 水及能源计量边界 | 区分能源、水等耗能工质及评价指标的边界，按适用要求处理 | “水和能源统计口径复核” |
| 产值估算 | 各产品产量乘单价，并核实价格依据 | “补充产值估算过程” |
| 增加值率偏高 | 核对中间投入、税金和各项来源；超过 25% 重点解释 | “增加值率偏高，复核依据” |
| 增加值过程不足 | 逐项检查数量、单价、分类和计算 | “补充增加值计算过程” |
| 单耗分母或分子不清 | 生产综合能耗、产品数量和分摊边界统一 | “单耗计算口径复核” |
| 不恰当的对标 | 核对行业、用途、对象、指标和标准条件 | “对标对象复核” |
| 先进结论缺乏依据 | 查可适用的先进值及比较条件 | “先进水平依据？” |
| 碳排放 | 核对电力、燃料、边界、因子年份及公式 | “碳排放计算复核” |
| 措施缺漏或与方案不符 | 对照工艺、公辅系统和措施表 | “该措施与前文核对” |
| 禁限用及淘汰设备 | 按设备型号、用途、适用范围和实施时间核对现行产业、节能及淘汰目录，不以其他项目结论代替查证 | “设备是否属于淘汰类，复核” |
| 节能措施实施进度 | 核对已建和新建部分、实施时间及可执行条件与项目进度是否一致 | “补充措施实施时间” |
| 节能量及节能率 | 对照基准、优化条件、参数及节能量汇总 | “补充节能率计算过程” |
| 节能比较基准不合理 | 对新建项目尤其核查基准设备是否满足当时适用的设计及能效要求，核对效率、运行条件和节能率来源 | “对比基准及节能率依据？” |
| 雨水回收效果 | 核对集水面积、降雨参数、收集及储水设施、用途和实际可替代用水量，避免仅按理论降雨量全额计效 | “回收能力和用途复核” |
| 可量化节能措施未汇总 | 对比各措施计算边界，排除重复后汇总可计量节能量 | “补充可计量节能量合计” |
| 地区节能降碳影响 | 对照消费量等价值、地区数据年份及公式 | “影响分析数据来源？” |
| 结论与摘要不同 | 逐指标对照摘要、正文和结论 | “前后不一致，复核” |
| 依据过期、重复或归类不当 | 查官方现行状态、实施时间、适用范围 | “标准现行性复核” |
| 附录附件与正文不同步 | 对照引用目录、图纸、计算及修改后数据 | “同步复核” |

“同上”按用户习惯使用；若所选位置和上下文无法识别所指问题，补充最少必要对象。发现一个系统确实不涉及，可记录“不适用及原因”，不制造批注。
