# 会后修改稿复核方法与批注写法

本方法依据多个已完成节能评审项目的会后批注归纳。历史稿名称有“审核”“批注”“反馈”等，且可能混有编制人员回复和后续轮次；应按实际内容、作者和版本链判断，不能将文件名中的“第一次批注修改”直接认定为评审单位首轮批注。本文件示例均为归纳的通用表述，不能作为任何项目事实或现行标准依据。

## 一、先确定审查基准

- 确认报告、回复表和专家意见是否对应同一项目、同一轮反馈。必要时对照报告封面、版本时间、章节内容和来稿目录；如存在多个无法分辨的版本，先查已有记录，仍影响判断时询问用户。
- 将专家意见拆成可核查的具体事项，定位回复表列出的章节、页码和报告中的实际内容。页码可能因版式改变而偏移，应以内容为准。
- 对照意见—回复—正文—佐证材料，判断实际已落实、部分落实、未找到、存在矛盾或需进一步核实。对无法独立验证的企业内部事实，不认定为真实或虚假。必要时在内部保留对应关系，不要求另做或外发一份表。
- 对已充分落实、没有其他问题的内容无需批注；对回复合理但正文缺少说明的内容，建议补充适当说明。遇到意见之间、意见与客观材料或现行规定之间不一致，指出冲突和待核实内容，不自行裁定专家结论。
- 对照首轮与后续稿时，不以原批注保留、消失或选中文字是否仍出现判断落实。选区很短、同一文字出现多次或正文已经改写时，先通过章节、表格、上下文和回复定位，再判断相关内容是否改到位；无法可靠对应时记录待核。

## 二、报告本身也要检查

依项目实际选择重点，不把下列清单变成每项必有问题：

1. **项目事实与边界**：建设单位、项目性质、实施进度、地点、备案和用地建筑情况；新建、扩建、原有与本项目边界，租赁区域、公用设备以及能耗是否重复或遗漏。
2. **产品、工艺与设备**：产品方案及产能依据，工艺与设备匹配，设备数量、规格、功率、能效等级、运行制度及新旧设备口径；生产、公辅、办公生活及特殊系统有无遗漏。
3. **计算与一致性**：核查重要输入、公式、单位、工作时数、负荷系数、统计范围及汇总；对照摘要、项目概况、设备表、计算表、章节分析和结论，发现一处变化时检查相关引用。必要时独立复算，区分明确算错与假设不明。
4. **能效和碳排放**：对标对象、标准适用性、比较口径和结论是否相符；能源消费、折标系数、碳排放边界与时点是否一致。法规标准以官方现行文本和项目适用情形核实，历史项目所用数值不自动沿用。
5. **节能措施与效果**：措施是否针对本项目设备和运行条件，是否说明计算基准、方法、参数与效果；不能仅凭套用节能率认定效果。
6. **证据与附件**：报告中的备案、合同、抄表、设计参数等是否有相应依据，缺失时指出需补的资料或说明；不强制要求提供与问题无关的全部原始材料。
7. **文本与版式**：检查明显错漏、前后用词、章节表格编号、单位和关键格式。服务于阅读与修改，不用细碎排版问题淹没技术问题。

结合历史批注，检查时尤其留意这些容易被套话掩盖的问题：设备运行数量、备用与运行工况是否吻合；项目实际是已建、拟建还是整改前后，全文时态和设备状态是否对应；主要生产工序是否有针对性的节能分析，而不只是写公辅设备；措施声称采用的群控、余热利用等是否在本项目方案中落实；面积、人数、班次、设备台数、用时等能否相互对应；相关修改是否同步反映在摘要、计算、结论和附件。发现问题按实际证据批注，不预设必然存在问题。

## 三、把问题写成能执行的批注

优先使用简短、口语化的沟通语气，依靠批注锚点明确对象，不套正式审查意见句式。数据不对直接写“复核”；问题一样写“同上”。必要时才补充一句对象、问题或修改方向：

| 情况 | 通用写法示例 |
| --- | --- |
| 数据有误 | “复核” |
| 问题一样 | “同上” |
| 事实缺失 | “开工、投产时间？” |
| 具体疑问 | “这台设备包含在前面的设备表里吗？” |
| 前后不一致 | “前后不一致，复核” |
| 依据不足 | “产能依据？” |
| 漏项 | “补充该系统用电” |
| 意见未落实 | “摘要表补充用水量” |
| 相关内容联动 | “同步复核” |

同一问题重复出现时按用户习惯写“同上”，不人为限制其使用次数。对有争议或锚点无法体现问题的情况，可补充辨认问题所需的最少内容；不要默认把重要问题写成一大段。确需引用专家意见时，注意区分原意见和本次反馈，不得将新增判断写成专家原话。避免嘲讽或无依据的断言。

对需要核验的事实，如项目是否设置某设备，可以直接问“有……吗？”，不要预设结论。建议删除、替换或修改具体数值须有充分依据；没有依据不替编制单位确定参数或结论。误加的空白批注、同一位置的重复批注和与锚点不对应的批注应清理或修正；不同位置的同一问题可按用户要求写“同上”，不得擅自删除输入文件中已有的他人批注。

## 四、优先次序和停止条件

优先处理项目边界、能源和碳排放计算、标准适用性、关键设备及可能影响核心结论的意见，再处理一般文字与格式问题。审查范围以用户指令为准，不以固定批注条数或篇幅衡量完成度。不能验证的关键依据、打不开的资料、缺失的意见或未覆盖的章节应在交付时如实说明；不要声称已全部落实或可以通过评审，除非有充分依据且属于用户要求。
