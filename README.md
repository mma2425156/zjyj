# zjyj

面向节能报告和节能整改报告的专家组总体意见编制技能。

将专家个人意见及项目资料放在工作目录，使用已安装的 zjyj 技能并说明任务，例如“汇总本项目的专家个人意见，编制专家组总体意见”。使用者应提供项目模板、评审资料和专家个人意见。缺少专家意见时，技能会询问是先按现有意见编制还是等待收齐。

优先使用项目模板。没有项目模板时，可使用技能目录中的通用模板。单位名称、项目事实及专家结论以当前项目资料为准。

仓库只包含通用方法和占位模板。项目资料由使用者在各自环境中处理。

## 会后修改稿批注

[zjpz](zjpz/SKILL.md) 用于对编制单位提交的节能报告会后修改稿进行复核，在 Word 中添加发回编制单位的批注。它与汇总专家组总体意见的 zjyj 分开使用；项目报告、专家意见和修改回复表留在各自项目目录。

新技能放在本仓库并不等于已经安装。实际使用前须按本机技能安装和共享环境规则完成安装，或在支持按路径读取技能的环境中直接指定其 `SKILL.md`。

## 国仕节能评审文件编制

[ZJPSYJ](zjpsyj/SKILL.md) 在最后一轮节能报告复核时，按指定报告和国仕模板编制节能评审意见、承办项目评审人员情况表和评审过程说明。发现疑点时在意见稿对应位置标黄并加短批注，待报告修正后同步更新三份文件的关联内容。安装后使用 `$zjpsyj` 调用。
